# Архитектура

Карта репозитория для планировщика aiflow. Держите её короткой и актуальной:
после заметных мержей обновляйте задачей `simple` «обнови ARCHITECTURE.md».

## Модули
- `path/` — назначение, ключевые файлы, входные точки.

## Соглашения
- Как устроены тесты, где лежат фикстуры, как запускать сборку.

## Внешние зависимости
- Библиотека — для чего; выжимки документации в `docs/references/`.
